TDS — Temporal Dominance of Sensations

使い方

  1. Panelist ID と Sample ID を入力します。
  2. 試料を口に含んだら Start を押します。
  3. 3秒のカウントダウン後、評価が始まります。
  4. その瞬間に最も優勢な感覚を3×3のボタンから1つ選択します。
  5. 評価開始から10秒後に「飲み込み」の合図が表示されます。
  6. 評価開始から25秒後に自動終了し、結果が自動保存されます。
  7. 次の Sample ID を入力し、Start を押して続けます。
  8. 最後に「全結果を送信」を押します。CSVもバックアップとして保存できます。

評価属性

その瞬間に最も優勢な感覚を1つ選択してください。 同じボタンをもう一度押すと選択が解除されます。
