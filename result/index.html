TDS — Temporal Dominance of Sensations

使い方

  1. Panelist ID と Sample ID を入力します。
  2. Start を押して評価を開始します。
  3. その瞬間に最も優勢な感覚を3×3のボタンから選択します。
  4. 同じボタンをもう一度押すと選択が解除されます。
  5. Stop を押し、「試料を確定」で結果を保存します。
  6. 次の Sample ID を入力して、同じ操作を繰り返します。
  7. 最後に「全結果を送信」を押します。

評価属性

その瞬間に最も優勢な感覚を1つ選択してください。
