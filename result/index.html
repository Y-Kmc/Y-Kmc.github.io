TDS — Temporal Dominance of Sensations

使い方

  1. Panelist ID と Sample ID を入力します。
  2. Start を押すと、3秒のカウントダウン後に評価が始まります。
  3. その瞬間に最も優勢な感覚を、3×3のボタンから1つ選択します。
  4. 同じボタンをもう一度押すと選択が解除されます。
  5. 評価開始10秒後に試料を飲み込み、評価はそのまま続けます。
  6. 評価開始25秒後に測定が自動終了し、結果が記録されます。
  7. すべての試験区を測定したら「全結果を送信」を押します。
